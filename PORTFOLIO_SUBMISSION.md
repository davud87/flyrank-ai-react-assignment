# Portfolio Submission

## Project Brief

TaskFlow AI is an accessible work-management application designed for individuals and small teams who need a clearer way to organize work across departments and workflow stages. Users can manage work through a Kanban board while an AI-powered planning assistant transforms rough requirements into structured tasks with suggested departments, priorities, labels, and actionable subtasks. I chose this project because project planning is a practical area where AI can reduce repetitive organization work while keeping the user in control of final decisions.
